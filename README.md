# P-value Lab

An interactive educational simulation for beginner and intermediate researchers exploring how p-values respond to:

- underlying effect size
- sample size
- variability
- random sampling variation

The app deliberately uses **“tends to”** rather than deterministic rules: repeated samples under the same underlying conditions can produce different observed effects and different p-values.

## Teaching model

The current version simulates two independent normally distributed groups with equal standard deviations and uses a two-sided large-sample comparison of means. The displayed 95% confidence interval uses the corresponding standard-error approximation.

This is an educational tool, not a substitute for study-specific statistical analysis.

## Run locally

Open `index.html` in a modern browser. No dependencies or build step are required.
