What does a 95% confidence interval mean?

If we repeatedly took new random samples and constructed intervals using the same 95% CI procedure, about 95% of those intervals would contain the true population parameter in the long run.

Common myth

“There is a 95% probability that the true value is inside this particular interval.”

That is not the frequentist interpretation. Below, the true population mean stays fixed. The sample — and therefore the interval — changes.

What changes when you change the settings?

Increase confidence from 80% → 99%: intervals get wider, but long-run coverage increases.

Increase n from 10 → 500: intervals get narrower because the estimate becomes more precise.

A correctly constructed 95% procedure still targets 95% coverage as sample size changes.

How is a CI related to a p-value?

For a two-sided test at α = 0.05, a corresponding 95% CI and hypothesis test tell the same significance story when they use the same statistical method.

Why the CI adds information: a p-value addresses compatibility with a null hypothesis. The confidence interval also displays the estimated effect and its precision. Two studies can both have p < 0.05 while having very different interval widths.

For differences, the usual null value is 0. For ratio measures such as risk ratios, odds ratios and hazard ratios, it is 1. The CI–p-value equivalence requires corresponding confidence intervals and hypothesis tests based on the same method.
