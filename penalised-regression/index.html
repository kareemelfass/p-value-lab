Penalised Regression Learning Lab

Learn ridge, lasso, and elastic net by changing the penalty yourself. One reproducible simulated dataset is used throughout so that differences come from the penalty, not from changing examples.

1. When to use penalised regression

Good situations for penalisation

  • Prediction is the main goal, rather than estimating one causal effect.
  • There are many predictors, including p > n, meaning more predictors than observations.
  • Predictors are correlated, so ordinary regression coefficients may become unstable.
  • You want shrinkage to reduce overfitting.
  • You may want variable selection. Lasso and elastic net can set coefficients exactly to zero. Ridge generally cannot.

Less suitable as a default

Be careful when the main aim is causal-effect estimation. Prespecified confounders should not be automatically deleted merely because they add little predictive information.

Decision process:

  1. Define the goal: prediction or causal interpretation.
  2. Decide whether sparsity is desirable.
  3. Inspect predictor correlation.
  4. Then tune the penalty using resampling.
Practical rule: penalised regression is a natural family to consider when the main problem is unstable prediction, many predictors, correlated predictors, or overfitting.

2. Why penalise?

Ordinary regression

Ordinary least squares minimises the residual sum of squares, the total squared difference between observed and predicted outcomes.

RSS = Σ(yᵢ − ŷᵢ)²

When predictors overlap strongly, different coefficient combinations can give similar predictions, so individual coefficients can become unstable.

Penalised regression

Objective = model loss + penalty

The penalty makes large coefficients costly. The model accepts some bias if this reduces variance and improves prediction in new data.

Core idea: shrink coefficients toward zero to control model flexibility.

3. Main terms

RegularisationConstraining model flexibility to improve stability and reduce overfitting.
PenaltyAn extra cost added to the fitting objective.
ShrinkagePulling coefficients toward zero.
Lambda, λControls how strong the penalty is.
Alpha, αControls the ridge-versus-lasso mixture in elastic net.
L1 penaltySum of absolute coefficient values. Used by lasso.
L2 penaltySum of squared coefficient values. Used by ridge.
Sparse modelA model with many coefficients exactly zero.
Active setPredictors currently having non-zero coefficients.
Cross-validationTraining on part of the data and evaluating on held-out observations.
Coefficient pathHow each coefficient changes across λ.
p > nMore predictors than observations.
Do not confuse: λ controls how much penalisation is used. α controls what kind of penalisation elastic net uses.

5. Ridge versus lasso

Ridge, L2

loss + λ Σβⱼ²

Shrinks coefficients but generally retains all predictors. Correlated predictors can share signal.

Lasso, L1

loss + λ Σ|βⱼ|

Can set coefficients exactly to zero, giving automatic variable selection. Correlated predictors may compete.
